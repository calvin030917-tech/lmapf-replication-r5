# `docs/` 文件说明 / File guide

[上一级文件索引 / Parent file guide](../FILE_GUIDE.md)

| 文件或目录 / File or folder | 中文说明 | English description |
| --- | --- | --- |
| [`ENVIRONMENT.txt`](ENVIRONMENT.txt) | 记录原 R5 实验的硬件、软件版本和串行计时范围。 | Records the original R5 hardware, software versions, and serial timing scope. |
| [`REVIEW_RESPONSE_CN.md`](REVIEW_RESPONSE_CN.md) | 按审稿意见列出稿件修订与对应的核验依据。 | Maps review comments to manuscript revisions and supporting checks. |
| [`SOURCES.md`](SOURCES.md) | 记录 Moving AI 地图、研究比较对象、文献检索和 ICML 样式来源。 | Documents the sources of the Moving AI maps, literature comparators, literature search, and ICML style. |
| [`manuscript_release.json`](manuscript_release.json) | 列出发布稿与关键数据的 SHA-256、英文主文页数和附录编排。 | Lists SHA-256 digests for release manuscripts and key data, the English body page count, and appendix placement. |
| [`planner_benchmark.json`](planner_benchmark.json) | 记录本地原版与优化版的配对基准，包括环境、一致性核验数量以及分配置和合并耗时。 | Local paired benchmark for the original and optimized planners with environment, parity check counts, and per-setting and pooled timings. |
