# 本轮修订与审稿意见的对应关系

| 审稿意见 | 修订位置与可核验证据 |
| --- | --- |
| 1. 出区均值无法由分组还原 | §3.1 定义 F、L、E。§5.2 和表6按分支及初始位置列分母、各段均值与出区步数总和。逐轨迹合计为 4,319 和 4,261 步。表5以三位小数分列出区与完工差和区间，4条逐配对差异在 r4_gate_vs_task_deltas.csv。 |
| 2. 两个历史样本无法识别对向受阻 | §4.1限定历史快照加权的估计对象，§4.2新增选择焦点后才标记对向的指定时刻设计。§5.4和表A1列24车同来源比较与名次分层，场景重采样区间同时给出原始与标准化差。 |
| 3. 案例 B 混有终点规则 | §3.4和§5.3公开机制样本选序及分母，独立的时层搜索在各自固定预留下比较留驻与释放，并核对种子在两种规则下的合法性。r4_case_replays.json 保存两种语义的合规路径。 |
| 4. 规划器及重放细节不足 | §3.3和算法1补充递归种子、撤销自身预留、预算边界和第1步完成后第2步的执行。表3及 small_cases.json 给参照与实际回退。三个图5案例检查了原序逐步重现来源的32步。 |
| 5. 主要联合判决缺少可查证的界 | 表10公布全部32个主界与分项判决，§4.3定义配对场景、绝对差、比值、调整及阈值。表B1、B2列完整交互和剩余距离补充比较，r4_joint_bounds.csv 另附0%与10%状态。 |
| 6. 跨车延误及外部适用性 | 表7和逐车CSV报告变慢人数及幅度、完工状态和第32步计数。§5.4、表8及A2补做两种种子构造、新地图、新任务流和同状态换种子试验。严重停滞及相同快照的事件差异均写入正文。 |
| 综述定位、语言及附件 | §1逐条辨析 RHCR、反事实让行、RL-RH-PP 和 PC-MAPF 的问题范围。表1、literature_evidence.tsv 给出每项证据的位置与阅读层次。中英文稿件共用结果，英文稿和英文图可独立阅读。 |
