# `manuscript_cn/` 文件说明 / File guide

[上一级文件索引 / Parent file guide](../FILE_GUIDE.md)

| 文件或目录 / File or folder | 中文说明 | English description |
| --- | --- | --- |
| [`paper_cn.txt`](paper_cn.txt) | 带标题、段落、表和图标记的中文正文，是 Word 构建的文本输入。 | Tagged Chinese manuscript text with headings, paragraphs, tables, and figures for the Word build. |
| [`refs.txt`](refs.txt) | 中文稿使用的参考文献条目和链接，按构建脚本的格式记录。 | Bibliography entries and links in the format consumed by the Chinese manuscript builder. |
| [`build_cn.py`](build_cn.py) | 把正文、文献、表格和图组装为中文 Word 稿。 | Assembles text, references, tables, and figures into the Chinese Word manuscript. |
| [`tables_cn.py`](tables_cn.py) | 从 R5 汇总及归档记录生成稿件使用的新表，并接入历史表。 | Builds manuscript tables from R5 and archived records and connects the historical tables. |
| [`tables_r4.py`](tables_r4.py) | 读取 R4 归档并组织稿件沿用的历史结果表。 | Reads the R4 archive and assembles the historical results tables reused by the manuscripts. |
